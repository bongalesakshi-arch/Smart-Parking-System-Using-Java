 🚗 Smart Parking System

 📌 About the Project

The **Smart Parking System** is a Java-based application developed to manage vehicle parking efficiently. It uses Java, JDBC, and MySQL to store and manage vehicle details.

The system allows users to park vehicles, remove parked vehicles, display vehicle details, search for parking slots, and calculate parking fees.

 🎯 Objectives

* To manage vehicle parking efficiently.
* To store vehicle details in a MySQL database.
* To avoid duplicate vehicle entries and occupied parking slots.
* To make vehicle searching and parking fee calculation easier.
* To perform database operations using JDBC.

 🛠️ Technologies Used

* Java – Application development.
* JDBC – Connecting Java with MySQL.
* MySQL – Storing vehicle information.
* Eclipse IDE – Writing and executing Java code.
* MySQL Workbench – Managing the database.

✨ Features

 1. Park Vehicle

* Enter vehicle type (Two-Wheeler/Four-Wheeler).
* Enter vehicle name and RTO number.
* Enter entry time and exit time.
* Select a parking slot.
* Prevent duplicate RTO numbers and occupied slots.

 2. Back Out Vehicle

* Remove a parked vehicle using its RTO number.
* Display a message if the vehicle is not found.

 3. Display Vehicles

* Display all vehicles currently stored in the database.

 4. Calculate Parking Fees

* Calculate parking fees using vehicle type and parking duration.
* Two-Wheeler: ₹20 per hour.
* Four-Wheeler: ₹40 per hour.

 5. Search Vehicle

* Search for a vehicle using its RTO number.
* Display the parking slot assigned to that vehicle.
